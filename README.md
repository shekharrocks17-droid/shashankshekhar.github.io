# NarrativesByShashank Website

A responsive multi-page author website built with plain HTML, CSS and JavaScript.

## Pages
Home, About, Books, Stories, Blog, Contact.

## Before publishing
1. Replace the placeholder book-cover blocks with your actual cover images.
2. Replace the contact email/social links with your real links.
3. Connect the contact form to Formspree, Netlify Forms, or another form provider if you want submitted messages.
4. Upload the files to GitHub Pages, Netlify, or another static host.
5. Point your custom domain's DNS to the host.

No paid Wix plan is required for the website itself.
